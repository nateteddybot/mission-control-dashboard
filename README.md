# 🧸 Mission Control - Nate's Command Center

Your personal productivity dashboard built with Next.js and Tailwind CSS. This is your centralized command center for managing ideas, content creation, project tracking, and personal metrics.

## 🚀 Quick Start

```bash
cd mission-control
./launch.sh
```

The dashboard will be available at: **http://localhost:3000**

## 📋 Features

### 🏠 Dashboard Overview
- Real-time Austin, TX time display
- Quick stats across all areas
- Recent activity feed
- Today's priority tasks
- Quick action buttons

### 💡 Ideas Backlog
- Capture business and content ideas
- Priority and status tracking
- Tagging system for easy filtering
- Progress tracking from idea to execution

### 📝 Content Pipeline
- YouTube-first content workflow
- Stage-based content management (Research → Outline → Script → Approval → Production → Published)
- Content type support (YouTube Main, YouTube Shorts, LinkedIn, Twitter)
- Due dates and assignment tracking

### ✅ Approvals Queue
- Review AI-generated content and proposals
- Approval workflow for business ideas and investments
- Priority-based queuing system
- Decision history tracking

### 📊 Project Tracker
- Multi-category project management (Work, Personal, Business, Content)
- Progress tracking with visual indicators
- Milestone management
- Deadline monitoring

### 📈 Personal Metrics
- **Consistency Metrics**: Content publishing, productivity, learning streaks
- **Shipping Velocity**: Projects completed, features delivered, time to ship
- **Growth Metrics**: Skills learned, content views, network growth
- **Financial Metrics**: Revenue, savings rate, investment growth

### ⚙️ Settings
- Notification preferences
- Content creation settings
- Dashboard customization
- AI assistant configuration
- Integration management

## 🛠 Technical Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Data**: Local storage (expandable to external APIs)
- **Icons**: Emoji-based (consistent across all OpenClaw tools)

## 🔧 Development

## 📊 Data Storage

Currently uses browser localStorage for simplicity and immediate functionality. Data persists across sessions but is local to each browser.

**Future Enhancement Options:**
- JSON file-based storage
- Database integration (SQLite, PostgreSQL)
- Cloud sync capabilities
- OpenClaw integration APIs

## 🔗 Integration with OpenClaw

This dashboard is designed to work alongside your OpenClaw AI assistant:

- **Morning briefs** generated by Teddy appear in the dashboard
- **Content approvals** flow through the approvals queue
- **Project updates** sync with OpenClaw's task management
- **Settings** configure Teddy's behavior and preferences

## 🎯 Usage Workflow

### Daily Routine
1. **Morning**: Check dashboard overview and today's tasks
2. **Content Creation**: Move items through the content pipeline
3. **Approvals**: Review and approve AI-generated proposals
4. **Project Updates**: Track progress on active projects
5. **Evening**: Review metrics and plan tomorrow

### Weekly Routine
1. **Review metrics** for goal progress
2. **Update project milestones**
3. **Content planning** for the upcoming week
4. **Ideas backlog** review and prioritization
